# Smart CLI Calculator 🧮

A menu-driven command-line calculator developed using Python. This project demonstrates Python fundamentals, modular programming, exception handling, and JSON-based data persistence.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Exponentiation
- Floor Division
- Input validation
- Exception handling
- Calculation history
- Persistent history using JSON

## Technologies Used

- Python 3
- JSON
- Git
- GitHub

## Project Structure

```text
Smart_CLI_Calculator/
├── main.py
├── operations.py
├── history_manager.py
├── history.json
├── .gitignore
└── README.md
```

Note: `history.json` is generated automatically when the first successful calculation is saved. It is excluded from GitHub.

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python main.py
```
